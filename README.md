# Maze Game

A 2D maze game written in C# using Raylib-cs.

## Features
- Keyboard-controlled player movement
- Wall collision detection
- Collectible coins
- Win condition at the finish line

## Built with
- C#, .NET
- Raylib-cs
- OOP design (Player, Wall, Coin, FinishLine classes)

## How to run
Open the project in Visual Studio and press F5.
